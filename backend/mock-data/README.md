# Generated reference mock data

These snapshots come from [frontend/src/data.js](../../frontend/src/data.js): catalogue/set-drink supplements, mock capacities, demo accounts with fake saved cards, and saved-group/history examples. They describe fixtures, not live browser state. Session retention timestamps are added when fixtures load.

From frontend, run `npm run export:mock` after changing fixtures, or `npm run check:mock` to verify snapshots. Direct equivalents are `node scripts/export-mock-data.mjs` and `node scripts/export-mock-data.mjs --check`.

The shared demo password is documented in the repository README. No real card transactions or backend service is involved.
